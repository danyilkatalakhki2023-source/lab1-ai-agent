# Журнал роботи AI-агента

## Структура запису

Кожен запис журналу має містити:

- **Запит** — що потрібно було виконати;
- **Відповідь або зміни** — що було створено, змінено або повідомлено;
- **Перевірка** — які фактичні перевірки виконано та з яким результатом;
- **Помилка** — виявлені проблеми;
- **Виправлення** — дії для усунення проблеми.

- **Запит:** явно виконати `.github/prompts/init.prompt.md` для підготовки та
  перевірки кросплатформного Python-проєкту на гілці `feature/hello-world`.
- **Відповідь або зміни:** виконано етапи `git-init`,
  `create-project`, `create-build`, `create-actions` і `check`. Створено
  `src/hello.py`, `src/__init__.py`, `tests/test_hello.py`,
  `requirements-dev.txt`, `ci.bat`, `ci.sh` і
  `.github/workflows/ci.yml`. README, ПІБ і групу збережено.
- **Перевірка:** на Windows створено `.venv` з Python 3.13.14; `ci.bat`
  успішно встановив залежності, виконав `test_BasicAddition`, створив
  `dist/hello.exe` і перевірив його вивід `Hello World`. YAML workflow
  розібрано через `yaml.BaseLoader`; перевірено matrix із трьома ОС, тригери,
  виклики скриптів, артефакти та Git-ігнорування службових каталогів.
- **Помилка:** попередній ввід `/init` викликав вбудоване створення
  `copilot-instructions.md` замість цього оркестратора.
- **Виправлення:** цей запуск виконано за явним запитом без використання
  вбудованого `/init`, без commit, push або злиття гілок.
- **Результати GitHub Actions:** ще не виконувалися; локальний успіх не
  означає успіх GitHub Actions.

## Запис 8 — виправлення генерації скриптів і workflow

- **Запит:** виправити помилки генерації після перевірки результату, спочатку
  оновивши skills, а потім застосувавши `create-build` і `create-actions`.
- **Відповідь або зміни:** у `build-and-test/SKILL.md` явно закріплено
  перехід у корінь за розташуванням скрипта, перевірку системного Python 3.13
  перед створенням `.venv`, обробку пошкодженого наявного `.venv`, запуск
  `pytest tests` і перевірку коду завершення та повного stdout executable через
  `subprocess`. У `github-actions/SKILL.md` додано вимогу
  `if-no-files-found: error` і прибрано дублювання перевірки executable у
  workflow. Виправлено `ci.bat`, `ci.sh`, `.github/workflows/ci.yml` та
  узгоджено `docs/usage.md` з явним запуском
  `.github/prompts/init.prompt.md`.
- **Перевірка:** оновлені скрипти перевірено локально на Windows і окремо
  скопійовано до нового тимчасового каталогу без `.venv/`, `build/` та
  `dist/`; запуск копії з іншого робочого каталогу сам створив `.venv`,
  виконав тест, зібрав `hello.exe` і перевірив його запуск.
- **Помилка:** попередня версія використовувала ненадійну перевірку `for /f`
  у `ci.bat`, не розрізняла відсутнє та пошкоджене `.venv`, запускала
  `pytest` для всього кореня та мала дублювальні executable-check кроки у
  workflow.
- **Виправлення:** перевірку перенесено до Python `subprocess`, додано
  явний контроль переходу в корінь і відмову без видалення пошкодженого
  середовища; workflow залишає перевірку скриптам і вимагає помилку при
  відсутньому artifact-файлі.
- **Перевірка YAML:** workflow успішно розібрано через `yaml.BaseLoader`;
  підтверджено одну matrix-job із трьома ОС, checkout, Python 3.13,
  виклики `ci.bat`/`ci.sh`, відсутність дублювальних Verify-кроків та
  `if-no-files-found: error` в обох upload-кроках.
- **Результати GitHub Actions:** ще не виконувалися.

## Запис 10 — завершення демонстрації помилки

- **Запит:** завершити демонстрацію помилки `test_BasicAddition`, відновити

- **Відповідь або зміни:** у `tests/test_hello.py` відновлено перевірку
  `assert add(2, 3) == 5`. Інші зміни не відкидалися.
- **Перевірка помилки:** під час демонстрації з тимчасовим очікуванням `6`

- **Повторна перевірка:** після відновлення очікування `5` `ci.bat` успішно
  виконав тест (`1 passed`), PyInstaller створив `hello.exe`, запуск
  завершився з кодом `0`, stdout дорівнював `Hello World\n`. Перевірка
  повноти та YAML workflow також пройшла.
- **Результат:** `git diff -- tests/test_hello.py` порожній. GitHub Actions
  фактично не запускалися. Commit і push не виконувалися.
