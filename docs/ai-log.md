# Журнал роботи AI-агента

## Структура запису

Кожен запис журналу має містити:

- **Запит** — що потрібно було виконати;
- **Відповідь або зміни** — що було створено, змінено або повідомлено;
- **Перевірка** — які фактичні перевірки виконано та з яким результатом;
- **Помилка** — виявлені проблеми;
- **Виправлення** — дії для усунення проблеми.

## Запис 1 — підготовка середовища

- **Запит:** перевірити доступну команду Python.
- **Відповідь або зміни:** команда `py --version` не знайдена. Натомість
  команда `python --version` працює.
- **Перевірка:** підтверджено доступність `python`.
- **Помилка:** команда `py` недоступна в середовищі Windows.
- **Виправлення:** надалі використовувати команду `python`, а не `py`.

## Запис 2 — створення інструкцій і документації

- **Запит:** створити інструкції спеціалізованого AI-агента та документацію
  архітектури й фактичної роботи для лабораторної роботи №1.
- **Відповідь або зміни:** створено інструкцію агента
  `.github/agents/build-engineer.agent.md`, документацію
  `docs/architecture.md` і цей журнал `docs/ai-log.md`; до README додано
  посилання на документацію.
- **Перевірка:** перевірено наявність і зміст створених файлів та YAML-заголовка
  агента.
- **Помилка:** на цьому етапі помилок не зафіксовано.
- **Виправлення:** не потрібне.

## Запис 3 — уточнення інструкцій агента

- **Запит:** уточнити формат і оркестрацію агента, критерії pytest, пакування
  PyInstaller та пов'язані положення архітектури.
- **Відповідь або зміни:** уточнено інструкцію
  `.github/agents/build-engineer.agent.md`, узгоджено
  `docs/architecture.md`, додано PyInstaller, цільові файли
  `dist/hello.exe` і `dist/hello`, правила артефактів GitHub Actions та
  критерій `test_BasicAddition`.
- **Перевірка:** перевірено текстові зміни у файлах документації та агента.
  Запуски програми, pytest, PyInstaller і CI не виконувалися.
- **Помилка:** на цьому етапі помилок не зафіксовано.
- **Виправлення:** не потрібне.

## Запис 4 — опис skills

- **Запит:** створити три інструкції skills для `project-scaffold`,
  `build-and-test` і `github-actions`, узгоджені з Python 3.13, `venv`,
  `pytest`, PyInstaller і кросплатформним CI.
- **Відповідь або зміни:** створено три файли `SKILL.md` у
  `.github/skills/project-scaffold/`,
  `.github/skills/build-and-test/` і `.github/skills/github-actions/`.
  Оновлено статус skills в `docs/architecture.md`.
- **Перевірка:** зафіксовано опис інструкцій і узгодження очікуваних шляхів,
  назв функцій та результатів між skills. Програму, тести,
  `requirements-dev.txt`, скрипти, workflow і залежності не створювали та не
  запускали.
- **Помилка:** фактичні перевірки проєкту, PyInstaller і GitHub Actions на
  цьому етапі не виконувалися.
- **Виправлення:** не потрібне.

## Запис 5 — уточнення середовища та PyInstaller

- **Запит:** уточнити в `build-and-test/SKILL.md` точну команду PyInstaller і
  правила створення та перевірки `.venv`.
- **Відповідь або зміни:** зафіксовано команду
  `python -m PyInstaller --onefile --name hello --distpath dist --workpath
  build/pyinstaller --specpath build src/hello.py`, де `python` означає
  інтерпретатор `.venv`. Описано створення відсутнього середовища системним
  Python 3.13, перевірку наявного `.venv` і зупинку без автоматичного
  видалення при невідповідності версії або непрацездатності.
- **Перевірка:** змінено лише інструкцію та журнал. Середовище, програму,
  скрипти й залежності не створювали та не запускали; PyInstaller, pytest і
  GitHub Actions не виконувалися.
- **Помилка:** фактичні перевірки цього етапу не виконувалися.
- **Виправлення:** не потрібне.

Запуски тестів, CI та інші перевірки проєкту в цьому журналі не заявляються,
оскільки на цьому етапі вони не виконувалися.
