# Використання AI-агента

## Вибір агента

У VS Code відкрий панель Copilot Chat і вибери агента
`build-engineer`. Він призначений для створення та перевірки
кросплатформного Python-проєкту Hello World.

## Запуск команд

Команди запускаються в чаті VS Code через меню prompt-файлів або введення
`/назва-команди`. Наприклад, `/create-project` запускає
`.github/prompts/create-project.prompt.md`, а `/check` — перевірку без
автоматичного виправлення.

`/init` — це команда чату VS Code, а не команда PowerShell. Її не слід
вводити в терміналі як виконувану програму.

## Порядок роботи з гілками

Гілка `develop` призначена для агента, skills, commands і документації. Перед
генерацією проєкту потрібно працювати у feature-гілці з назвою формату
`feature/...`. Команда `/init` перевіряє цю умову й у `develop` зупиняється.

Рекомендований порядок команд:

1. `/git-init`;
2. `/create-project`;
3. `/create-build`;
4. `/create-actions`;
5. `/check`.

Або використай `/init`, який оркеструє цей порядок у поточному сеансі агента.
Після помилки наступні етапи не запускаються.

## Результати

Локальні результати перевірок і результати GitHub Actions фіксуються окремо.
Виконувані файли пакування та службові каталоги не комітяться. Перед
заявленням успіху потрібно мати фактичний результат відповідної перевірки.
