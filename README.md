# Лабораторна робота №1

## Тема

Створення спеціалізованого AI-агента для генерації програми Hello World,
тестів і конфігурацій GitHub Actions для Windows, Linux та macOS.

## Мета роботи

Створити спеціалізованого AI-агента, який генеруватиме програму Hello World,
тести до неї та конфігурації GitHub Actions для автоматизованого запуску
перевірок у середовищах Windows, Linux і macOS.

- Python
- віртуальне середовище `venv`
- `pytest`
- PyInstaller
- PyYAML
- GitHub Actions
- операційні системи Windows, Linux і macOS
